# Project Rules: ACUSTIC_RX_G474 (НПФ «АМК Горизонт»)

## 1. Авторство и документация
Во всей сопроводительной документации, отчетах и спецификациях обязательно указывать:
* **Организация**: НПФ «АМК Горизонт»
* **Разработчик**: зам. начальника ОП Смирнов С. Г.

## 2. Правила Git (Коммиты и Пуш)
* **Строго по прямому указанию**: Коммиты и пуш выполняются **совместно и ТОЛЬКО по прямому указанию пользователя** (например: «закоммить», «отправь в репозиторий», «сделай пуш»).
* **Запрет несогласованных действий**: Категорически запрещено делать локальные коммиты или пушить в удаленный репозиторий без явного запроса пользователя.
* **Скрипты экономии токенов**: Для выполнения коммита и пуша без расхода токенов агента подготовлены готовые скрипты:
  * В командной строке Windows: `git_push.bat "сообщение коммита"` (или двойным кликом — запросит сообщение интерактивно).
  * В Bash: `./git_push.sh "сообщение коммита"`.

## 3. Модификация исходного кода
* **Запрет несогласованных правок**: Никаких изменений в исходных файлах (`.c`, `.h`, `.s`, `.ioc`) без прямого подтверждения или указания пользователя.
