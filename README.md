# ACOUSTIC_SYNC_RX (STM32G474CET3)

Прошивка приемника-синхронизатора (RX) электромагнитного/акустического канала межприборной синхронизации скважинного каротажного комплекса на базе микроконтроллера **STM32G474CET3 (LQFP48)**.

---

## 1. Назначение и функции
Приемник предназначен для приема кодированного синхросигнала от передатчика через индукционный/электромагнитный канал (через акустический изолятор прибора), выделения точной временной метки, компенсации разницы частот опорных кварцевых генераторов и автономного удержания синхронизации при пропадании сигнала.

### Основные возможности:
- **Высокочувствительный цифровой корреляционный приемник** на базе SIMD-инструкций Cortex-M4.
- **Адаптивный фильтр слежения 2-го порядка ($\alpha$-$\beta$ фильтр)** для отслеживания разности частот кварцев TX и RX и аппаратной подстройки периода таймера `TIM2`.
- **Режим автономного удержания (Holdover)** с термокомпенсацией ухода кварца по встроенному термодатчику TMP235 при прохождении каверн и проводящих пластов.
- **Аппаратный синхроимпульс** (`TIM2_CH4`) для запуска АЦП геофизических каналов основного прибора.
- **Телеметрический опрос по однопроводной линии Single-Wire UART** ($500\,000\text{ бод}$) с передачей статуса, величины дрейфа и отношения сигнал/шум (SNR).

---

## 2. Аппаратная архитектура и тактирование

### Тактирование
- Вход внешнего кварцевого генератора 16 МГц на выводе `PF0` (HSE Bypass).
- PLL конфигурирует системную тактовую частоту **SYSCLK = 84 МГц**.

### Оцифровка сигнала (АЦП и DMA)
- Входной сигнал с аналогового тракта оцифровывается модулем **ADC1** (канал `ADC1_IN2` на `PA1`).
- Передача отсчетов в кольцевой буфер ОЗУ выполняется аппаратно через **DMA1 (Канал 1)**.
- Прерывание DMA (`DMA1_Channel1_IRQHandler`) инициирует цифровую обработку отсчетов в реальном времени.

---

## 3. Алгоритм цифровой обработки сигналов (DSP)

Обработка выполняется в прерывании АЦП `ADC_Process_ISR` с оптимизацией под ядро Cortex-M4 (FPU/DSP):

1. **Дифференциальное детектирование и вычисление мощности**:
   - Используются SIMD-инструкции `__SHSUB16` и `__SMUAD` для быстрого вычитания соседних отсчетов и возведения в квадрат.
   - Аппаратное вычисление корня `sqrtf` формирует мгновенную огибающую входного сигнала.
2. **Скользящее интегрирование (Moving Average)**:
   - Оконный интегратор по длительности одного бита (66 отсчетов $\approx 427.4\text{ мкс}$) накапливает энергию символа.
3. **Корреляционная свертка с кодом Баркера (31 бит)**:
   - Свертка накопленных 31 значений с эталонной биполярной последовательностью $M[i] \in \{-1, +1\}$.
   - При совпадении формируется узкий корреляционный пик, превышающий уровень шума.
4. **Адаптивная оценка SNR и порога**:
   - Отношение пиковой мощности свертки к фоновому шуму: $\text{SNR} = 10 \cdot \lg\left(\frac{P_{\text{peak}}}{P_{\text{noise}}}\right)$.
   - Защита от деления на ноль при низком уровне помех.

## 4. Система адаптивного слежения и удержания (SyncTracker)

Управление фазой и периодом синхронизации разделено на 4 состояния:

```
[ SEARCH ] ---> (Синхропосылка обнаружена) ---> [ LOCKED ]
                                                     |
                                            (Потеря сигнала)
                                                     |
                                                     v
[ LOCKED ] <--- (Сигнал восстановлен) <--- [ HOLDOVER ]
```

### 1. Поиск (SEARCH)
- Прибор сканирует входной поток АЦП до обнаружения валидного корреляционного пика с $\text{SNR} \ge \text{SNR}_{\text{thresh}}$.
- По первому пику выполняется фазовая привязка таймера `TIM2`.

### 2. Слежение (LOCKED)
- Используется $\alpha$-$\beta$ фильтр 2-го порядка:
  $$\hat{T}_{k} = T_{k-1} + \Delta T_{k-1}$$
  $$\text{Residual} = T_{\text{raw}} - \hat{T}_{k}$$
  $$T_{k} = \hat{T}_{k} + \alpha \cdot \text{Residual}$$
  $$\Delta T_{k} = \Delta T_{k-1} + \beta \cdot \text{Residual}$$
- Рекомендуемый период записывается в аппаратный регистр перезагрузки `TIM2->ARR`, ликвидируя разницу частот кварцев TX и RX с точностью до долей микросекунды.

### 3. Автономное удержание (HOLDOVER)
- При попадании в каверну или сильно проводящий пласт амплитуда сигнала падает ниже порога.
- Прибор **не сбивает фазу**, а переходит в экстраполяцию:
  $$T_{\text{holdover}}(t) = T_{\text{locked}} + K_{\text{temp}} \cdot (T_{\text{sensor}}(t) - T_{\text{lock}})$$
- Температура непрерывно считывается датчиком **TMP235** (`ADC4_IN3`, PB12).
- Накопленный фазовый уход составляет **$< 1\text{ мкс}$ за минуту** полного отсутствия сигнала.

### 4. Восстановление (RE-LOCK)
- При выходе из каверны прибор мгновенно возвращается в режим слежения без ложных скачков фазы.

## 5. Протокол телеметрии Single-Wire UART ($500\,000\text{ бод}$)

- **Линия связи**: полудуплексный Single-Wire UART на выводах `PA9` / `PA10`.
- **Команда опроса от мастера**: `0x37` (ASCII `'7'`).
- **Ответ приемника**: упакованная 9-байтовая структура `OutputPacket_t`:

```c
typedef struct __attribute__((packed)) {
    uint8_t  sync_status;  // 0: SEARCH, 1: LOCKED, 2: HOLDOVER
    float    difference;   // Текущий уход часов в микросекундах (us)
    float    snr;          // Отношение сигнал/шум последнего импульса
} OutputPacket_t;
```

## 6. Карта выводов (Pinout LQFP48)

| Pin | Вывод | Имя в коде | Назначение |
|---|---|---|---|
| **5** | `PF0` | `OSC_IN` | Вход внешнего генератора 16 МГц (HSE Bypass) |
| **9** | `PA1` | `ADC1_IN2` | Вход АЦП — прием синхросигнала 154 кГц |
| **12** | `PA4` | `GPIO_Output` | Разрешение/блокировка аналогового усилителя |
| **16** | `PB0` | `GPIO_Input` | Вход тестового генератора |
| **25** | `PB11` | `TIM2_CH4` | **Выход аппаратного синхроимпульса** |
| **26** | `PB12` | `ADC4_IN3` | Вход АЦП для термодатчика TMP235 |
| **29** | `PB15` | `LED_RX` | Светодиодная индикация статуса |
| **31** | `PA9` | `USART1_TX` | Half-Duplex Single-Wire UART (500 кбод) |
| **32** | `PA10` | `USART1_RX` | Half-Duplex Single-Wire UART (500 кбод) |
| **37** | `PA13` | `SWDIO` | Интерфейс отладки и прошивки SWD |
| **38** | `PA14` | `SWCLK` | Тактовый сигнал отладки SWD |
