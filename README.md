# ACOUSTIC_SYNC_RX (STM32G474CET3)

Синхронизатор акустического прибора (приемник синхросигнала) на базе микроконтроллера **STM32G474CET3 (LQFP48)**.

## Основные характеристики
- **Микроконтроллер**: STM32G474CET3 (LQFP48)
- **Тактирование**: Внешний генератор 16 МГц (ATX-H12-F-16000MHz-G100-1) на `PF0` (HSE Bypass) -> PLL -> **SYSCLK = 84 МГц**
- **Несущая частота сигнала**: 154 кГц (синхрокод Баркера / М-последовательность 31 бит x 66 отсчетов = 2046 точек)
- **Период повторения посылок**: 2.0 секунды (168 000 000 тактов при 84 МГц)
- **Интерфейс связи**: Single-wire полудуплексный UART на скорости 500 000 бод

## Назначение выводов
| Pin | Вывод | Назначение | Описание |
|---|---|---|---|
| **5** | `PF0-OSC_IN` | `RCC_OSC_IN` | Вход тактового сигнала 16 МГц от генератора D5 |
| **9** | `PA1` | `ADC1_IN2` | Вход АЦП — прием сигнала синхронизации (несущая 154 кГц) |
| **12** | `PA4` | `GPIO_Output` | Выход разрешения/блокировки усилителя (1 - вкл, 0 - выкл) |
| **16** | `PB0` | `GPIO_Input` | Вход тестового генератора |
| **25** | `PB11` | `TIM2_CH4` | Выход аппаратного синхроимпульса |
| **26** | `PB12` | `ADC4_IN3` | Вход АЦП для термодатчика TMP235A2DCKR |
| **29** | `PB15` | `GPIO_Output` | Выход управления светодиодом (1 - вкл, 0 - выкл) |
| **31** | `PA9` | `USART1_TX` | Полудуплексный UART (500 кбод) |
| **32** | `PA10` | `USART1_RX` | Полудуплексный UART (500 кбод) |
| **37** | `PA13` | `SWDIO` | Отладка SWD |
| **38** | `PA14` | `SWCLK` | Отладка SWD |

## Сборка и открытие
Проект настроен для среды **STM32CubeIDE**.
Файл конфигурации периферии: `ACUSTIC_RX_G474.ioc`.
