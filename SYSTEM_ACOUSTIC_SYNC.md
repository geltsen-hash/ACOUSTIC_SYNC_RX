# СИСТЕМА МЕЖПРИБОРНОЙ СИНХРОНИЗАЦИИ СКВАЖИННОГО КАРОТАЖНОГО КОМПЛЕКСА
## Комплексная техническая спецификация и описание архитектуры (TX + RX)

---

## 1. Общее назначение системы
Система предназначена для высокоточной временной синхронизации модулей скважинного каротажного прибора (излучающего и регистрирующего), разделенных акустическим изолятором. 

Передача синхросигнала осуществляется по электромагнитному (индукционному) каналу связи через изолятор. Приемник выделяет временную метку с субмикросекундной точностью, непрерывно компенсирует разницу частот и температурный дрейф кварцевых генераторов обоих модулей и обеспечивает бесперебойную выдачу синхроимпульсов даже в условиях полного затухания сигнала (каверны, проводящий буровой раствор).

```
+--------------------------------------------------------------------------------------------------+
|                                    СКВАЖИННЫЙ ПРИБОР                                             |
|                                                                                                  |
|  +------------------------+      ЭМ / Акустический канал      +-------------------------------+  |
|  |   ПЕРЕДАТЧИК (TX)      |       через изолятор              |       ПРИЕМНИК (RX)           |  |
|  |   STM32G474CET3        |==================================>|       STM32G474CET3           |  |
|  |                        |   154.4 кГц / 31-бит М-код        |                               |  |
|  | * Цикл ровно 2.000 с   |   (пачка 13.25 мс, каждые 2.0 с)  | * SIMD DSP-коррелятор (M4)    |  |
|  | * Мостовой ШИМ (TIM1)  |                                   | * Alpha-Beta трекер частоты   |  |
|  | * Dynamic Power Save   |                                   | * Holdover + термодатчик TMP  |  |
|  +------------------------+                                   +---------------+---------------+  |
|              ^                                                                |                  |
|              | UART (Стендовая настройка LC)            TIM2_CH4 (Синхроимп.) | Single-Wire UART |
|              v                                                                v (500 кбод)       |
|    [ Стенд инженера ]                                              +--------------------------+  |
|    (Подбор конденсатора)                                           | Основной модуль каротажа |  |
|                                                                    | (АЦП зондов и телеметрия)|  |
|                                                                    +--------------------------+  |
+--------------------------------------------------------------------------------------------------+
```

## 2. Физический уровень и параметры синхросигнала

| Параметр | Значение | Описание и реализация |
|---|---|---|
| **Период повторения посылок** | **$2.000000\text{ с}$** | Ровно $168\,000\,000$ тактов при системной частоте $84\text{ МГц}$ |
| **Несущая частота ($f_0$)** | **$154.41176\text{ кГц}$** | $84\text{ МГц} / 544$ (период ШИМ `ARR = 543`) |
| **Код синхронизации** | **31-битная М-последовательность** | Полином генератора: $X^5 + X^2 + 1$ (автокорреляция без ложных пиков) |
| **Длительность одного бита** | **66 периодов несущей** | $544 \times 66 = 35\,904$ тактов системной шины ($\approx 427.43\text{ мкс}$) |
| **Длительность пачки** | **2046 периодов несущей** | $31\text{ бит} \times 66\text{ пер/бит} = 2046$ периодов ($\approx 13.25\text{ мс}$) |
| **Вид модуляции** | Фазовая / амплитудная манипуляция | Формирование комплементарным двухтактным мостовым каскадом |

## 3. Архитектура передатчика (TX) — `ACUSRIC_TX_474`

### 3.1. Тактирование и стабильность 2-секундного интервала
- **Тактирование**: Внешний кварцевый генератор 16 МГц на выводе `PF0` (HSE Bypass) $\to$ PLL $\to$ **SYSCLK = 84 МГц**.
- **Базовый таймер цикла (`TIM5`)**:
  - 32-битный таймер с предделителем `PSC = 0` и периодом `ARR = 167 999 999` ($168\,000\,000$ тактов).
  - Работает в непрерывном аппаратном автоперезапуске (`TIM_CR1_ARPE`).
  - Синхронизация пачек выполняется по аппаратному флагу обновления `TIM_SR_UIF` без программного сброса `CNT`, что обеспечивает абсолютную стабильность фазы без накопления ошибки во времени.

### 3.2. Силовой тракт и генерация несущей (`TIM1`)
- Таймер `TIM1` формирует двухтактный комплементарный ШИМ с настраиваемым аппаратным Dead-Time:
  - `PA8` (`TIM1_CH1`): прямой выход на драйвер полумоста.
  - `PB13` (`TIM1_CH1N`): инверсный выход.
- Управляет силовым резонансным контуром излучателя.

### 3.3. Динамическое управление питанием (Power Saving)
Для исключения нагрева внутри скважинного снаряда в паузах между посылками ($\approx 1.98\text{ с}$) силовая часть полностью обесточивается:
1. За **$30\text{ мс}$** до излучения включается высоковольтный преобразователь: `PB14` (`DIS_TPS` = 1).
2. За **$10\text{ мс}$** до излучения активируется мостовой драйвер: `PB11` (`DIS_DRV` = 0).
3. Излучается пачка кода ($13.25\text{ мс}$), включается индикатор `LED_TX` (`PA5`).
4. По завершении пачки драйвер отключается (`DIS_DRV` = 1), преобразователь обесточивается (`DIS_TPS` = 0).

### 3.4. Стендовый режим настройки резонанса (TUNE / SWEEP)
Используется **только на этапе сборки/настройки прибора на стенде**:
- По сервисному UART (`PA9/PA10`, 115200 8N1) подается команда `GTUN<ARR>` (например, `GTUN544`).
- Передатчик включает непрерывную генерацию несущей (`work_mode = TUNE`), позволяя инженеру осциллографом снять резонансную кривую излучающего контура.
- По формуле Томсона рассчитывается точный номинал подстроечного конденсатора:
  $$C = \frac{1}{(2\pi f_0)^2 \cdot L}$$
- Команда `GNOR` безопасно возвращает передатчик в штатный режим импульсов 2.0 с (`work_mode = NORM`).

## 4. Архитектура приемника-синхронизатора (RX) — `ACUSTIC_RX_G474`

### 4.1. Входной тракт оцифровки (АЦП + DMA)
- **Вход сигнала**: `PA1` (`ADC1_IN2`) подключен к выходу аналогового полосового усилителя.
- **DMA**: Аппаратный кольцевой буфер `DMA1_Channel1` непрерывно передает отсчеты АЦП в память без загрузки ядра.
- **Прерывание**: `DMA1_Channel1_IRQHandler` вызывает обработчик цифровой фильтрации `ADC_Process_ISR`.

### 4.2. Алгоритм цифровой обработки сигналов (DSP)
Реализован на базе SIMD-инструкций ARM Cortex-M4 и FPU:
1. **Дифференциальное детектирование огибающей**:
   - Быстрое вычитание соседних отсчетов `__SHSUB16` и перемножение `__SMUAD`.
   - Аппаратно ускоренное извлечение корня `sqrtf` формирует огибающую мощности.
2. **Скользящий интегратор бита (Moving Average)**:
   - Интегрирование огибающей по окну длительности одного бита ($66$ отсчетов $\approx 427.4\text{ мкс}$).
3. **Корреляционная свертка с кодом Баркера**:
   - Свертка с эталонным 31-битным биполярным вектором $M[i] \in \{-1, +1\}$.
   - При совпадении фазы формируется узкий корреляционный пик высокой амплитуды.
4. **Адаптивный порог и расчет SNR**:
   - Расчет отношения пика к шуму: $\text{SNR} = 10 \cdot \lg(P_{\text{peak}} / P_{\text{noise}})$.

### 4.3. Адаптивный трекер и режим удержания (SyncTracker)

```
       +------------------+
       |   Старт прибора  |
       +--------+---------+
                |
                v
       +------------------+   Синхропосылка обнаружена (SNR >= порога)
       |      SEARCH      | ------------------------------------------+
       |  (Поиск первого  |                                           |
       |       пика)      | <-----------------------+                 |
       +------------------+                         |                 |
                                                    | Потеря          v
                                               синхронизации +------------------+
                                               (> 10 минут)  |      LOCKED      |
                                                    |        | (Слежение:       |
                                                    |        |  Alpha-Beta      |
                                                    |        |  фильтр TIM2)    |
                                                    |        +--------+---------+
                                                    |                 |
                                          +---------+---------+       | Потеря сигнала
                                          |     HOLDOVER      |       | (каверна / пласт)
                                          | (Экстраполяция по | <-----+
                                          |  датчику TMP235)  |
                                          +-------------------+
                                                    |
                                                    | Сигнал обнаружен вновь
                                                    v
                                          [ Восстановление RE-LOCK ]
```

1. **Фаза SEARCH (Поиск)**:
   - Ожидание первого пика, превышающего порог обнаружения. По факту детектирования выполняется разовый сброс `TIM2->CNT = 0` для грубой привязки фазы к передатчику.
2. **Фаза LOCKED (Слежение и Soft DPLL)**:
   - Счетчик `TIM2->CNT` **не сбрасывается**, что исключает джиттер от шумов АЦП.
   - Фильтр 2-го порядка ($\alpha$-$\beta$) оценивает реальный базовый период следования:
     $$\hat{T}_{k} = T_{k-1} + \Delta T_{k-1}$$
     $$\text{Residual} = T_{\text{raw}} - \hat{T}_{k}$$
     $$T_{k} = \hat{T}_{k} + \alpha \cdot \text{Residual}$$
     $$\Delta T_{k} = \Delta T_{k-1} + \beta \cdot \text{Residual}$$
   - Пропорционально-интегральный регулятор DPLL измеряет мгновенную фазовую невязку $\Delta \varphi = \text{CNT}$ в момент пика и подстраивает период:
     $$\text{Pull} = K_p \cdot \Delta \varphi + K_i \cdot \int \Delta \varphi \, dt \quad (K_p = 0.35, \; K_i = 0.05)$$
     $$\text{ARR}_{\text{next}} = T_{k} + \text{Pull}$$
   - Рекомендуемый период записывается в `TIM2->ARR`, плавно стягивая фазу к нулю без скачков.
3. **Фаза HOLDOVER (Автономное удержание)**:
   - При затухании сигнала в каверне `SyncTracker` переходит на математическую экстраполяцию:
     $$T_{\text{holdover}}(t) = T_{\text{locked}} + K_{\text{temp}} \cdot (T_{\text{sensor}}(t) - T_{\text{lock}})$$
   - Температура измеряется датчиком **TMP235** (`ADC4_IN3`, PB12).
   - Таймер `TIM2` непрерывно отсчитывает 2.0-секундный шаг. Уход фазы удерживается на уровне **$< 1\text{ мкс}$ за минуту** блэкаута (при ширине окна пробуждения $50\text{ мс}$).
4. **Восстановление (RE-LOCK)**:
   - При выходе из каверны число прошедших циклов вычисляется через $N = \operatorname{round}(\Delta t / T_{\text{nominal}})$, и DPLL плавно стягивает остаточную фазу без разрыва шага оцифровки геофизики.
5. **Выход аппаратного синхроимпульса**:
   - Канал `TIM2_CH4` (`PB11`) генерирует калиброванный импульс запуска для внешних АЦП основного прибора.

## 5. Протокол телеметрии Single-Wire UART ($500\,000\text{ бод}$)

Для мониторинга качества синхронизации центральный процессор каротажного прибора опрашивает приемник по однопроводной полудуплексной линии связи.

- **Линия связи**: Single-Wire Half-Duplex UART (`PA9` / `PA10`, 500 000 бит/с, 8N1).
- **Команда мастера**: байт `0x37` (ASCII символ `'7'`).
- **Ответ приемника**: упакованная 9-байтовая структура `OutputPacket_t`:

```c
typedef struct __attribute__((packed)) {
    uint8_t  sync_status;  // 0: SEARCH, 1: LOCKED, 2: HOLDOVER
    float    difference;   // Текущий фазовый уход (мкс)
    float    snr;          // Отношение сигнал/шум последнего принятого импульса
} OutputPacket_t;
```

## 7. Программный комплекс верификации и симуляции (Renode + Python)

В каталоге `Renode_Sim/` развернута среда сквозного тестирования:
1. `stm32g474.repl`: Точная аппаратная модель MCU STM32G474 (Cortex-M4, таймеры, PythonPeripheral RCC, АЦП, UART).
2. `simulate_scenario2_bench_tune.py`: Стендовый тест режима настройки резонанса TUNE/SWEEP и расчет емкости контура.
3. `simulate_tx_rx_system.py`: Совместная симуляция тракта TX $\to$ Акустика $\to$ RX с учетом акустической задержки, начального сдвига частоты кварцев ($\pm 25\text{ ppm}$) и теплового дрейфа.
4. `test_holdover.py`: Тест автономного удержания фазы в каверне при полном отсутствии сигнала.
5. `simulate_scenario4_uart.py`: Тест протокола опроса телеметрии Single-Wire UART на скорости 500 кбод.
